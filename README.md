### epOS

A records-first operating system I designed and built to run my own practice.

The premise is that a decision you cannot find again is a decision you will make twice. So every ruling is a record rather than prose: a permanent code minted on creation and never reused, an explicit owner, the rationale and the source, and a supersede-never-delete rule so a revision keeps the reasoning that produced it. One canonical marker per fact, so two documents can never both claim to be true. A seam rule that keeps operating knowledge and technical documentation cross-linked rather than copied, because copies drift and links do not.

It is built to be read by an agent as much as by a person. A governed library of skills gives a Claude agent the standards, the terminology locks and the routing rules, so the answer it returns is the governing one rather than a plausible one.

Nine routing classes decide where an output lives before it is produced. A ruling is not closed when it is written, only when its paired action is verified. That second rule is the one that mattered: the failure mode was never missed decisions, it was rediscovered ones.

**Built on:** ClickUp for records · GitHub for the coded backbone, scripts, configuration and session history · Figma for the design system · a published portfolio as the public layer · a Claude agent over a governed skill library, with Python, PowerShell and Make beneath it.
